# 关键词回复

关键词自动回复，带命中统计。

**这个插件就是 [nekoe-plugins README](../../README.md) 里那个完整例子** ——
它能跑，说明文档是准的。

## 它演示了什么

- 自己建数据表（`autoreply_hits`）
- 消息钩子（`@ctx.on_message()`）
- 配置项（规则用「关键词=回复」的多行文本写）
- 管理接口（统计 / 规则 / 清空）
- 插件自带管理页（页内 `<script>` 会被执行）
- 按 (群, 关键词) 各算各的冷却，防刷屏

## 用法

装好后在「插件 → 已安装 → 关键词回复 → 配置」里写规则，每行一条：

```
帮助=发送「帮助」看用法
群规=请先看群公告
```

群成员发「帮助」就会收到对应回复。

## 配置项

| 键 | 说明 |
|---|---|
| `ar_enabled` | 总开关 |
| `ar_pairs` | 规则，每行一条 `关键词=回复` |
| `ar_cooldown` | 同一个群里同一个关键词的冷却秒数（0 = 不限） |
