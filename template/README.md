# 插件骨架

复制这个文件夹，改两个文件就能写出自己的 Nekoe 插件：

- `metadata.json` —— 名称、版本、作者、描述、配置项默认值
- `main.py` —— 逻辑（`setup(ctx)` 是入口）

**完整文档**：[nekoe-plugins 根目录的 README](../README.md)（ctx 能力全表、
完整例子、容易踩的坑）。

## 快速上手

1. 把文件夹改名成你的插件名，`metadata.json` 里的 `name` 也改成一样的
2. 改 `main.py` 里的逻辑（骨架里注释掉了各能力的用法，取消注释就能用）
3. 丢进 Nekoe 的 `data/plugins/` 下
4. 管理界面「插件」页点右上角「重新加载」，**不用重启**

## 四条最重要的约定

1. **只跟 `setup(ctx)` 打交道，不要 `import` 主程序** —— 打包成 exe 后模块名会变
2. **模块顶层别碰数据库** —— 核心（数据库 / AI）就绪后才会调用 `setup()`
3. **命令和消息钩子的处理函数记得 `return True`** —— 否则消息会继续往下走
4. **名字都加插件前缀** —— 配置键、表名、页面里的 JS 函数名，避免跟别人撞车

## 调试

- 「概览 → 实时日志」里能看到 `ctx.log()` / `ctx.warn()` 的输出
- 改完代码点「重新加载」，它会把插件挂的管理接口一起换成新的
- 插件报错会显示在插件卡片上，不会静默失败
